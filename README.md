# vivi-images

ビビの画像ファイルを管理するリポジトリです。登録済み画像は78枚で、mainブランチの直下に配置しています。

## キャラぷからの呼び出し

次の形式のNを、登録済みの画像番号に置き換えます。

```markdown
![](https://raw.githubusercontent.com/shotasn/vivi-images/main/N.webp)
```

通常画像（1番）の例：

```markdown
![](https://raw.githubusercontent.com/shotasn/vivi-images/main/1.webp)
```

NPC識別子のVIVは、フォルダ名とは別のものです。現在VIVフォルダはないため、URLに /VIV/ を追加しないでください。

## 登録番号

[登録ファイル一覧](IMAGE_INDEX.csv)には番号・ファイル名・画像URL・Git blob SHAを記載しています。番号が飛んでいる箇所は未登録です。存在しない番号を補完して使わないでください。

この一覧はファイルの存在を確認したものです。画像の内容や用途を目視で検証した対応表ではありません。場面と番号の対応は、キャラ設定の対応表で管理してください。

## プロンプトで管理する表示方針

- 場面が変わったとき、感情が大きく動いたとき、登録画像と一致する特徴的な行動を取ったときに表示を検討する。
- 場面専用画像、具体的な動作、表情の順を基本に、描写との一致度で選ぶ。
- 対応する描写やセリフの直前に画像タグを挿入する。
- 同じ状況での無意味な再表示を避け、適切な画像がなければ省略する。
- READMEや一覧がキャラぷに自動で取り込まれる前提にはせず、必要な対応表・ルールをキャラぷのプロンプトにも記載する。

## 更新時の方針

既存画像の番号・ファイル名・配置を維持し、既存URLを保ちます。画像の削除、上書き、移動、改番は行わず、新規画像は未使用の番号で追加します。

将来VIVフォルダが必要になった場合は、直下の画像を残したまま複製し、追加先の内容が元画像と一致することを確認します。現在のルートURLを使う構成では複製は不要です。

画像を追加した場合は、このREADMEの枚数とIMAGE_INDEX.csvも更新してください。
